# 全局调试日志与快照

最后更新：2026-11-16

适用版本：7.15.0。此功能只保存本机文件，不自动上传。

7.16.1相机保存前/重载后逐项复核均记录camera.transaction.final_readback，包含phase、node、expected、actual及verified，读取失败保留error。SDK节点缓存刷新记录camera.sdk.node_cache_invalidated或node_cache_refresh_unavailable。写入报告readbacks同时保留两阶段读数；报错后可区分“刚写入读回一致”和“UserSet重载后不一致”，不再只有节点名。不据此猜测缺失的历史实际高度；仍需新版本实体复测确认。

## 操作入口

工具箱侧栏底部点击“调试日志”。面板提供刷新日志、保存快照、导出调试包、打开日志目录。日志每两秒更新，隐藏面板后暂停刷新；查看时保留用户滚动位置。

“保存快照”将当前状态JSON和工具箱主窗口PNG截图保存在调试目录；截图仅在明确点击时产生。“导出调试包”先补一份当前状态JSON，再将已有日志及快照打包为新ZIP。ZIP不覆盖现有文件。现场报错后可直接导出，查看设备、节点、上下文及操作顺序。

默认目录为 `%LOCALAPPDATA%/VTStudioToolbox/diagnostics/`。启动自动创建按时间、进程和随机标识区分的会话日志；每个日志2MB，最多两个轮转备份，目录保留最近20个日志文件和20份状态JSON，删除对应孤立截图。调试目录不可写时不阻止业务程序启动，面板显示写入权限问题。

## 记录范围

- 四个工作区的任务开始、完成、消息及异常；SOL读取和应用仅记录路径/结果，不记录密码或请求对象。
- Python未处理异常、后台线程异常、Qt消息及Python警告；异常保留调用栈。
- MVS枚举、打开/关闭、SDK节点读写、命令、当前选择器上下文、当前值、访问权限、支持项和SDK错误。
- 相机读取/对比自动保留快照；写入成功或失败保留报告。GUI错误自动保存当前状态，后台线程只保存自身错误/报告，不跨线程读取Qt表单。
- 状态包括当前工作区、转换/合成设置及数量、脚本规则白名单、相机当前设置/固定值/设备快照/计划/报告。无效图像参数保存校验错误，避免为快照修改表单。

不扫描任意窗口控件，不保存SOL密码、私钥、完整SOL、C#源码或原始训练图片。键名含password、token、secret、api-key、authorization、credential、密码等字段脱敏；文本中的凭据赋值、Bearer和私钥块脱敏。手动截图会包含当前显示内容，设备身份和文件路径保留用于本机排查。

CLI也记录本地日志，不向stdout追加日志，原JSON封装及退出码不变。

## 文件契约

状态JSON为 `vt-debug-snapshot/1`，包含version、session、created_at、reason、data，以及手动截图时的screenshot文件名。单份JSON上限4MB，超出时用错误说明替代data。reason区分manual、camera-inspect、camera-comparison、camera-write-passed及异常事件。

调试ZIP包含 `vt-debug-bundle/1` 的manifest.json以及实际选中的日志/JSON/PNG。输入文件合计不超过32MB，单文件超过12MB则跳过，manifest记录files和skipped。文本在导出时再次脱敏；不附加环境变量、命令行参数、源码目录或其他文件。日志、调试目录和发布构建由Git忽略，本机诊断不混入公开安装包。

## 触发锁定IO的排查与处理

用户已在实际相机确认：触发设置占用线路时，LineMode可能变为只读。7.15不再在预检阶段直接拒绝有选择器上下文的只读LineMode，而标为“关闭帧/行触发后校验”。预检不会修改触发状态。

点击写入后仍先重新核对计划及设备状态，再关闭帧/行触发并读回Off，随后重新读取LineMode的范围、支持项和可写性，校验后才写IO。然后按原依赖顺序配置并开启行触发、设置Timed曝光，最后开启帧触发。关触发后仍固定只读的线路不会强写，错误包含物理Line、当前值及目标值。

失败恢复也先关两路触发，恢复ROI，再于曝光恢复可能重开LineStart之前恢复LineMode及其他IO，最后恢复原触发状态。预检后其他客户端改动可读LineMode仍使计划失效。用户集保存前失败尽力恢复，保存开始后不宣称完整回滚。

数字IO页显示读回的每路当前模式、访问权限及支持模式。输出模式下拉在可写时按已选线路支持项更新；只读时保留Strobe/Output参考选择及原配置值，因为触发锁可能使枚举只剩当前项，实际支持性在关闭触发后复核。写入后清除旧能力表，避免旧读数冒充新状态；不静默改接线或将只读状态解释为线路永久固定。

模拟验证覆盖触发锁、永久只读、失败恢复和外部修改，现场设备完整写入及成像仍单独验证。
