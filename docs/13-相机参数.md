# 相机参数计算与设置

最后更新：2026-11-14

当前实现7.12.0。默认按“材料＋横纵百分比余量→目标视野→目标精度→实测周期走料→倍分频→图高和空档校验”计算。每周期实际走料距离是倍分频计算的物理依据，不再仅按图高凑整数倍率。计算结果不作为实体相机采集及无拉伸的现场证明。

## 操作流程

### 每页两组预设

材料与视野、编码器与图高、采集触发、数字IO、专业标定、成像各有“预设1/预设2、应用预设、保存当前”。选择组号不改参数；应用只替换本页的预设字段，不写设备；保存当前只更新该页所选组，重开程序仍可使用。两组初始值相同，来源为用户需求文档第5节的MFS摘录，未取得原始MFS，不宣称全量恢复。

初始材料页带入CL042黑白、4096px、7μm、25mm固定镜头；编码器页为手动1/3/1和Height3200；触发页为FrameBurstStart/Line3、LineStart的FrequencyConverter、A相Line1；IO为上升/下降沿、差分、300/1000ns、Line0曝光开始和Line4软触发频闪25000μs；成像页为Width3296、OffsetX500、Mono8、19μs、Gain2.9079、gain_1400x、HB、黑电平30，手动行频30000但限制关闭。专业标定页只带当前项目15%容差、cycle策略和100行取整规则，不编造实测标定值。

参考未提供的材料长宽、距离和周期走料等保留当前输入。材料页预设包含机型基础信息，因此可切换参考相机并清除本页固定值；其他页不清除材料固定值。参考ROI不适合当前传感器时拒绝成像页应用并提示，不静默缩小。原参考ROI/图高也可能不覆盖当前产品，仍执行覆盖和周期校验。

预设文件为%LOCALAPPDATA%/VTStudioToolbox/camera-page-presets.json，schema为vt-camera-page-presets/1，pages下六个页面各含两个字段字典，只保存PAGE_KEYS允许的字段。初始化不写文件，点击保存当前才原子替换；读取上限1MB，损坏时提示并临时使用参考值。预设是GUI本机偏好，不嵌入相机配置schema2或随仓库上传。

选择完整相机型号，程序自动带入并锁定原生分辨率、像元和固定镜头：CL024黑白/彩色为2K、7μm、KF1228/12mm；CL042黑白/彩色为4K、7μm、AF2524M-M42/25mm；CS050 V5黑白/彩色为2448×2048、3.45μm、HF0628/6mm。不猜Bayer排列，彩色格式保持现场值。原生行数2/3不等于线扫输出图高。

主页面分为材料与视野、编码器与图高、采集触发。前两页使用双列工作条件输入：名称/单位在上，数值或选择器在下，输入提交后自动更新结果。材料页始终显示工作距离，未固定的距离、材料宽W、长L、横纵总余量均可直接编辑；只读显示目标视野宽、长。默认横向10%、纵向2%。不显示计算方向下拉或专门切换按钮：没有固定约束时以最近一次编辑决定计算依据，固定约束优先。

### 固定数值

仅“材料与视野”数字输入框右侧的加减按钮改为锁定图标；编码器、IO、成像、专业标定和其他工具的数字控件保持原有操作。点击灰色开锁图标固定当前数值，图标变橙色闭锁，输入置灰只读；再点一次解除固定。键盘输入、步进及计算回填均不能改变固定数值。默认不固定任何项，沿用自动互逆输入。

- 固定工作距离、修改材料宽度时，反算未固定的横向余量。
- 固定横向余量、修改距离时，反算未固定的材料宽度。距离和余量均固定时，材料宽度由这两项确定。
- 距离、材料宽度、余量等固定条件不相容时，不覆盖固定值，清空失效结果并提示“固定值冲突”，停止写入。按输入框显示精度判定一致性，固定的显示值始终保持原样。
- 正常切换参考相机保留固定值；如果固定焦距或像元等与新预设不相容，拒绝切换并提示解除对应固定项。打开另一份配置、导入MFS或读入设备计算条件会开始新的计算上下文并清除固定状态。固定状态只用于当前GUI会话，不写入现有配置schema，CLI计算不受影响。

未固定数值仍按以下规则计算：

- 修改工作距离：保留该距离，按相机及镜头计算横向视野，再计算横向总余量`100×(视野宽/W−1)`并回填。负余量表示视野比材料窄，不再截成0，阻止写入。
- 修改材料宽长、横纵余量或光学参数：先由材料和余量得到目标视野，再反算工作距离。选择其他参考相机时使用相同材料/余量条件重算距离。编码器、IO或成像参数不改变当前光学计算依据。
- 自动回填的距离和余量阻断编辑信号，不会触发另一方向计算；界面保留数值控件显示精度，内部计算结果在结果区显示。旧legacy专业标定继续保留原有已知精度/实测视野含义。

结果表新增“材料像素（宽×高）”：`ceil(W/dx) × ceil(L/dy)`，不包含余量；悬停显示两者乘积，表示按材料矩形尺寸规划的像素总数。线扫未标定时Y仍为规划值。默认示例为1862×3724px，整张取图仍为2048×3800px。编码器页填写每周期实际走料距离、P/R、有效计数倍率、每帧间隔圈数，查看或调整图高与最少空档；自动模式隐藏三个因子编辑器，在右侧显示计算结果，手动模式显示编辑器。面阵隐藏编码器页及行触发。

“更多参数”紧邻当前表单下方；表单高度按当前可见字段收拢，超过窗口可用空间时内部滚动，移除原属性表中被撑大的空白区域。数字IO仍用MVS属性表。交互结构参考[海康镜头选型工具](https://www.hikrobotics.com/cn/machinevision/service/machinevisionTool/)，不调用网站进行计算。

数字IO、专业标定及成像位于更多参数。右上语言、连接、文件三项统一152×36，语言框不再因宽度≤140被共享控件判成28px紧凑模式。结果区以独立QScrollArea承载，布局保留最小内容高度；摘要根据实际宽度计算换行高度。展开连接区、明细或缩窗时允许向下滚动，不压缩文字叠到表格。大窗口显示覆盖示意，图内背景与周期空档分别命名。四个工具继续共用styled_controls.py。

## 默认计算模型与验收示例

目标视野宽Fx=W×(1+横向余量/100)，目标视野长Fy=L×(1+纵向余量/100)。线扫横向精度dx=Fx/N；后续光学计算以Fx为依据，图高以Fy为依据，不再只用材料长度决定所需图高。新流程使用传感器全宽N，不通过缩小ROI冒充视野改变；手动ROI不足时阻止写入。快速估算WD=dx×f/(p/1000)，其中p单位μm、f及WD单位mm。

线扫目标dy=dx。自动倍分频求出实际dy后，产品实际最少行数=ceil(L/dy)，目标视野所需行数=ceil(Fy/dy)；另保留square_pixel_product_lines=ceil(L/dx)作为目标行数。建议Height按height_rounding（默认100行）向上取整，再对齐设备Height步长，也可手动输入。未测量时只按目标dy规划图高，不能据此决定倍分频。实际ROI覆盖为Width×dx、Height×dy，可能因取整略大于目标值。面阵取dx=dy=max(Fx/Nx,Fy/Ny)，同时满足两个方向覆盖。

设相邻帧周期的实测走料为S(mm)，输入有效计数B=P/R×有效计数倍率×每帧间隔编码器圈数。只填写S，程序派生脉冲密度k=B/S、材料占比L/S、材料通过期间的输入计数k×L。计数倍率必须按实际输入链核实，不将统计选项当作硬件计数模式已修改。

目标总变频比G=S/(B×目标dy)=1/(k×目标dy)。预分频、倍频、后分频各限1～5，与设备min/max/inc取交集后搜索整数因子，使实际比例M/(Pre×Post)接近G；设备支持更大数值也不放宽本项目上限。实际周期行数C=B×M/(Pre×Post)，实际dy=S/C。新工位workflow_settings的frequency_tolerance_percent默认15%，已有配置及CameraSettings旧默认1%不静默改变。实际Y与目标差异超过所设容差时阻止写入；手动因子也必须在1～5，超限旧手动配置拒绝导入，自动配置会按新上限重算。完成采样计算后才校验floor(C)−Height≥cycle_idle_lines（默认100，必须大于0）；容量不足时报告冲突，不增大倍率改变物理采样。

测量示例：W=200mm、L=400mm、横向10%、纵向2%、CL024/12mm、N=2048、p=7μm、1000P/R、×1、每Z周期一圈，另假设实测S=429.6875mm（不是现场默认值）：

| 输出 | 结果 |
|---|---|
| 视野 | 220mm |
| 目标视野宽×长 | 220×408mm |
| 目标视野最少行数 | 3799行 |
| 快速估算工作距离 | 184.151785714mm，界面显示184.152mm |
| dx及规划dy | 0.107421875mm/px |
| 产品最少行数 | 3724 |
| 材料像素宽×高 | 1862×3724px，不含余量 |
| 默认建议Width×Height | 2048×3800 |
| 预分/倍频/后分 | 1/4/1 |
| Z周期总行触发数 | 4000 |
| 图内背景 / 周期空档 | 76行 / 200行 |

同一实测S下，手动Height=3900时仍为1/4/1，背景176行、空档100行；Height=4000仍为1/4/1，但因空档不足而阻止写入。有效计数为×2/×4时，相应倍率为2/1，实际空间采样保持一致。

保持S=429.6875mm，纵向余量改10%后目标视野220×440mm、最少4096行、建议Height4100，但倍分频仍为1/4/1、周期4000行，容量不足需调整工位或留白。不能因增加画幅而自动改成5倍。

## 无拉伸与标定边界

只知道图高和每周期输入脉冲数，无法决定正确的纵向采样。材料60mm、周期走料90mm、1000有效输入脉冲、目标0.02mm/行时，理论材料3000行、周期4500行、总比4.5。7.11不再推荐超出上限的1/9/2，而在1～5内取1/5/1：周期5000行，实际dy=0.018、误差−10%，材料实际3334行，按此重新计算图高。默认±15%可接受该精度；容差较严格时仍阻止写入。图高和周期容量独立校验，不隐瞒近似后的尺寸变化。

cycle_travel_mm已移到常用编码器页，0表示未知。缺少S时自动模式显示“待测量”，不输出倍分频节点，也不声称周期行数、可用空档或预计外部行频已确定；光学和图高规划保留，但对比不能ready、写入停止。手动模式可查看所填因子的周期脉冲数，但仍需S才能校验实际采样并写入。S必须对应输入的同一帧周期，编码器计数与走料应成比例；现场仍须用未缩放原图核对打滑和实际尺寸。

主平面及实测视野方式保留：thin_lens令u=WD+主平面偏移，dx=p(mm)×(u−f)/f，反算WD=f×(1+dx/p)−偏移。未知主平面填0仍为近轴模型；法兰后焦不能作为主平面偏移。快速模式保留远距公式，用户示例184mm对应快速模式，薄透镜模式为约196.152mm。畸变、对焦及实物距离须实测校准。

原有FOV/已知精度、产品长度÷原始占用行数标定以及按每圈走料求Y精度的算法在原计算配置/专业标定中可用，输入必须基于未缩放图像。不能把周期走料长度、产品长度、图高或产品间距互相替代。

## 频率、触发与设备写入

稳定匀速预计外部行频=最高产能/60×C；平均图像行输出=最高产能/60×Height。两者分开，不拿平均图像输出当采集期实际行频。实际峰值、曝光及带宽按设备读回核对。AcquisitionLineRateEnable=False不写AcquisitionLineRate，也不把其未启用值作为真实行周期。

自动写入需要三个倍分频节点范围完整可读；cycle与原pitch策略都使用有界整数搜索和Y误差容差。原pitch策略依据实测每圈走料，保留其原有含义。周期平均行数为非整数时提示核对边界计数和分频相位，不宣称busy/缓存/触发无丢失已验证。

采集触发页分别显示帧触发IO、可编辑的行触发源（默认“频率转换器输出”）及编码器A相输入IO。编码器IO对应EncoderSourceA，行触发对应LineStart上下文中的TriggerSource=FrequencyConverter；面阵隐藏后两项。7.12新增可选line_source字符串，旧配置缺省FrequencyConverter，保存时记录当前值；MFS导入保留LineStart.TriggerSource。离线提供常见参考选项，连接后读取LineStart上下文的支持枚举，对比和写入按设备能力校验。选择非FrequencyConverter来源时不写倍分频节点，不继续声称编码器倍分频决定该源的周期行数/行频，相关结果为null或“待核对”，图高按输入精度规划；EncoderModuleOut仍配置编码器输入，直接Line源配置相应输入IO，其余来源不配置A相输入。手动行频限制如启用，需明确输入上限。实际节拍和采样需按该信号源确认。帧触发开始后采满Height结束一张图，Continuous/单触发一帧/Timed及原依赖写入顺序保留。下位机负责帧相位，工具不写板、不追加图像白边。示意图居中不表示现场产品位置已执行。

## 配置及兼容性

schema仍为vt-camera-config/2。7.7新增vertical_margin_percent：新GUI及camera-template/camera-plan无配置时为2%；旧文件缺失时为-1，表示沿用原image_vertical_margin_mm及原逐项行数取整，不静默给旧文件加百分比余量。新界面可将该兼容值改为0～1000%后使用新逻辑。legacy专业标定继续沿用原毫米留白。该字段的配置需要7.7或以上版本读取。schema1仍执行旧留白合并与Y来源legacy确认。workflow_settings默认示例为200×400/横向10%/纵向2%/2K彩色/12mm/1000P-R，不是现场实测数据。

计划vt-camera-plan/1及配置记录输入和最终整数因子。7.10保留cycle字段名、配置schema2和原pitch/legacy含义，但旧cycle配置S=0也必须补充测量后才可写入。新增metrics：cycle_calibrated、frequency_pending、input_counts_per_cycle、encoder_counts_per_mm、material_cycle_fraction、material_encoder_counts、target_cycle_line_count。cycle未知S时encoder_counts_per_mm、material_cycle_fraction、material_encoder_counts、target_cycle_line_count为null；自动cycle还令frequency_solution、line_triggers_per_cycle/lines_per_product、required_line_rate_hz、recommended_line_rate_hz、cycle_idle_available、cycle_travel_for_square_mm为null，并省略PreDivider/Multiplier/PostDivider节点。settings中的因子保留输入值，不能当作待测量状态下的推荐值。

material_width_px、material_height_px、material_pixel_count表示不含余量的材料矩形像素；实测后高度按实际dy计算。target_fov_width_mm/target_fov_height_mm为目标视野，coverage_width_mm/coverage_height_mm为ROI覆盖；未测量时后者是规划。y_sampling_error_percent在实测cycle模式表示实际Y相对目标的误差，未知S时为null。lines_per_product仅为周期总行触发C的旧兼容别名。

framing_source继续为material/distance/legacy；GUI按最后编辑项及固定条件选择，CLI明确使用配置字段。material横向百分比须大于-100，distance可包含显示取整得到的-100；实际视野不足由覆盖检查阻止写入。legacy原0～1000%约束保留。

设备读取会取得各LineSelector上下文的LineSource支持项以及触发输入支持项，操作后恢复选择器，不为获取列表改LineMode。若某输入模式下信号源不可读，明确使用待核对的参考选项；后续对比仍按设备实际能力校验。已加载但不受支持的旧值保留以便操作者修正，不静默换值。中文/English切换参数名称和已知枚举显示文字，SDK字符串及JSON保存值保持不变；未知厂商枚举保留原文。未连接设备时仅提供需求摘录中的曝光开始有效/软触发有效作为参考，不宣称为设备完整支持列表。

相机能力由设备读回；配置JSON可保存完整工位设置，换产品复用标定。所有四页使用同一共享控件模块styled_controls.py；主表单36px，表格或窄字段28px。保留原有NoButtons输入方式、模型/delegate、编辑、信号和自动背景参考禁用语义。动态新控件也初始化，数字字段及内嵌编辑框避免重复边框。

枚举→选择序列号/传输类型→读取尺寸→对比→查看差异→写入UserSet1。修改配置或目标使对比失效；设备任务期间锁定配置文件菜单/SDK目录入口。读取/对比报告另采集帧/行TriggerDelay、LineDelayEnable、帧/行缓存、FrameTimeout及残帧策略、TDI/Binning。附加项仅读回，不猜单位强写；FrameTimeoutTime在型号描述中存在单位文字冲突，留给设备/型号资料确认。相机延迟不等于下位机相位，避免未知叠加。

对比以后，计划节点、用户集状态或可读延迟/缓存/超时状态改变会拒绝过期写入；动态频率值变化不会被误判为静态配置修改。选择器读写均按上下文并恢复。只读附加状态出现在读取/执行记录与导出JSON中。

## 有序写入和恢复

不抢占/停止其他程序采集，不运行视觉流程。写入先关闭帧/行触发、保存全部可读计划原值、复位ROI偏移，再配置模式、IO、格式及ROI。依据同型号GenICam约束，先配置并开启LineStart，再在LineStart选择器上下文设置Timed和曝光，最后开启帧触发。BurstFrameCount在帧选择器上下文设置；不在错误选择器下强写依赖节点。

各项读回后核对允许行频→UserSet1 Save→Load→再次核对→设置默认用户集并读回。Save开始前失败尽力恢复格式、尺寸、依赖模式及原触发状态；曝光恢复也考虑LineStart依赖。切换模式前不可读或恢复失败的原值明确列入未核实项，不能宣称完整恢复。Save开始后失败报告用户集可能变化，不能声称完整回滚。

## SDK、MFS与CLI

已补充D:/MVS安装目录发现，枚举包含虚拟GigE/USB3（SDK类型0x10/0x20）。物理设备UID沿用GigE:序列号、USB3:序列号；虚拟设备使用VirtualGigE:序列号、VirtualUSB3:序列号，并增加virtual布尔字段，避免同序列号混淆。独立GenTL采集卡传输类型未接入，不按GigE结构强转。使用虚拟设备时由用户以管理员身份启动程序，工具不自动提权或修改目录权限。

虚拟功能的边界以本机MVS帮助“添加虚拟设备”（GUID-2148F185-ADF7-4A98-A469-66AE5F133AEF.html）为准：虚拟相机主要支持宽高、像素格式，触发源仅软触发或采集卡触发；虚拟采集卡也只有部分出图、软触发/快速软触发、定时器配置可用。不为通过测试跳过原对比校验，不把虚拟设备支持情况当成外部IO、编码器或UserSet持久化证明。

camera_model.py纯计算；camera_sdk.py加载本机MVS x64 Python封装/运行库；camera_transaction.py比较、附加读取、有序写入及恢复；camera_ui.py第四页。厂商SDK/DLL不随包分发。VT_MVS_DIR指定封装位置，VT_MVS_RUNTIME指定运行库；冻结版从安装目录绝对预加载DLL及本进程依赖路径，切换SDK目录需重启。

JSON/MFS上限1MB；CLI拒绝覆盖已有输出。MFS只解析已支持ROI、曝光/增益、倍分频、格式和部分触发字段到模板，不执行文件，不使用全量FeatureLoad，不声称完整恢复原MFS或推断外部编码器P/R。单帧/Timed等由工具模板设定；原配置未摘录的延迟/缓存等从目标设备读取。网络IP/包长等保持现场设置。

CLI入口不变：camera-template、camera-plan、camera-info、camera-inspect、camera-compare、camera-write。设备命令支持--sdk-dir。camera-write接受有效对比原始JSON，重新核对设备和当前状态；真实写入及UserSet流程须操作员执行。无设备的camera-info成功返回空列表；纯计算/配置/UI测试不作为现场成像、触发无丢失或断电保持证明。
