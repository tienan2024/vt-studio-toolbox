# SOL 脚本变量读取

最后更新：2026-11-12

6.9新增独立的“应用脚本到SOL”操作，能够通过本机VM SDK编译当前生成脚本并另存新方案，详见[脚本自动应用](12-SOL脚本自动应用.md)。本文的只读说明适用于“打开SOL”及参考变量清单；“使用此模块变量”仍只改变当前产品模板。

## 操作

在“脚本生成与测试 → 变量清单”点击“打开 SOL”，选择方案。受保护方案会弹出隐藏字符的密码输入框，密码仅用于当前读取，不写入产品JSON、日志或磁盘。读取在后台进行，期间不能关闭窗口；取消密码后保留当前清单。可重新打开文件重试。

读取完成后选择流程、脚本。即使多个流程的脚本同名，也会显示模块ID以区分。输入、输出分组显示原始名称、VM类型及数量；这份参考只读，不运行或修改原方案。没有脚本时显示0个模块。不需要安装VM或加载SDK，不初始化脚本模块。

顶部来源切换可返回“当前生成脚本”，双击变量名、说明或按F2修改。上下组之间的分界可拖动，各组独立滚动。读取新的SOL会替换当前SOL参考，不覆盖产品配置。

## 应用到当前 NG 模板

“使用此模块变量”适用于本工具的NG汇总脚本：标准五种输入名称/类型（允许缺少aiResult），其余输入均为int类型XXXResult，且输出正好是本工具四项标准输出。应用前需要确认每个独立信号对应哪一个NG类型；已有同名映射可预选，未知映射不猜测。NGtype仍在左侧粘贴完整类型列表；不读取其运行时绑定值。

确认后导入产品信号，重置端口别名、说明及此前导入的自定义USER CODE，使用当前NG模板和标签规则重新生成；不是恢复任意原脚本的业务逻辑。缺少aiResult时自动补上兼容输入并关闭AI判定，Label_name仍保留。原始端口名有不同拼写、其他类型、非标准四项输出或任意脚本逻辑时，仅能查看原始清单，不自动套用模板。应用后还可以编辑当前模板名称；在VM内配置端口、绑定和编译仍需操作者完成。

## 读取格式与边界

sol_reader.py只用Python标准库读取ZIP容器中的VmServer.xml和MoudleFrame，不解包到磁盘、不执行C#。通过模块ID及流程成员表关联数据。模块帧按完整记录边界解析：版本5为256字节UTF-16LE名字，版本7为512字节UTF-8名字，长度为大端整数；数量、记录边界、重名和尾部长度均检查。只从脚本的DynamicInData/OutData字段解析端口XML，排除非百分号包围的内置时间字段，不从源码里的任意XML猜端口。

支持本机样例已验证的帧版本5、7及标准ZIP传统密码保护；不保证其他版本或加密方式。文件最大2GB，条目最多30000，VmServer.xml最多16MB，模块帧最多128MB、10000条记录；XML拒绝DTD/实体。未知格式、损坏、密码缺失/错误均报错，不回退到运行VM方案。源文件不写入；密码不会作为命令行参数或产品字段保存。本轮不增加SOL的CLI命令。

## 实测

用户提供的方案成功读取2个脚本模块：内装外形检测/脚本1（ID9）为8输入、4输出；虚线切有无检测/脚本1（ID23）为10输入、4输出。第二个模块原始没有aiResult。只读提取前后源文件SHA-256相同。验证记录仅保存变量元数据，未保存密码或解密后的完整方案。此结果证明读取该方案的变量成功，不等于运行其业务流程通过。
