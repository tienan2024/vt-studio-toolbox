# 工具箱整合与转换协议

最后更新：2026-10-27

## GitHub交付

源码仓库为https://github.com/tienan2024/vt-studio-toolbox，Windows便携包通过GitHub Releases单独分发。源码包含legacy/vt-engine.exe及其来源与指纹文件；release/、build/、verification/、虚拟环境、密钥和本机设计缓存由.gitignore排除。便携包需完整解压，两个EXE共用_internal。仓库不包含生产图片和官方VT读取器程序集；原生读取器验证在其他电脑缺少本机环境时会跳过。

## 范围与架构

v6.0 将此前独立缺陷工具与用户的 VT Studio 尺寸处理工作流整合在同一 Windows 窗口。`toolbox.py` 使用 QStackedWidget 承载 `ConverterPage` 与嵌入的缺陷 `MainWindow`；切换页面不销毁状态。`theme.py` 维护共享样式。关闭窗口时若任何模块仍在处理，拒绝关闭并定位到对应页面。

转换使用 VT_STUDIO_v5.0.exe 原来嵌入的 Windows `vt-engine.exe`。已通过 .NET 包静态提取和原应用公开协议类核对，不运行旧 GUI，也不宣称恢复了原始完整开发工程。调用前校验固定 SHA-256，详见 [核心说明](../legacy/README.md)。

## 原转换核心协议

进程 stdin 首行是 UTF-8 JSON，无 BOM：

```json
{"Input":"输入目录","Output":"本批images目录","Width":3200,"Height":3960,"White":false,"Recursive":true,"CopyXML":true,"AllowClip":false}
```

处理期间 stdin 必须保持打开；EOF 会让原核心取消任务。取消发送独立一行 `stop`。stdout 每行一个 JSON，`type` 是 log、progress、done 或 fatal。`report` 包含 `Total`、`OK`、`Skipped`、`Failed`、`Cancelled`，字段大小写沿用原协议。

`legacy_bridge.py` 使用隐藏子进程和读流线程，将报告转给 Qt 工作线程。取消超时才终止该适配层启动的子进程。stderr 有限保留，消息逐行写入本批 events.jsonl，防止一次性把大日志加载到内存。

## 几何、文件与点集

已用位置编码像素实测：左上角 (0,0) 固定；目标较小时保留左上角像素，裁去右侧/下方；目标较大时右侧/下方填 0 或 255。原图不做重采样。预览缩略图仅供显示，不用于实际文件输出。

保留原文件名。BMP / PNG 输出统一落入每批 images 文件夹。若递归目录中出现同名图片，或启用 XML 复制时存在来自不同目录的同名配套 XML，适配层在运行前拒绝，不自动重命名。输入与输出目录必须分离，输出不可位于输入子目录。

`CopyXML` 仅原样复制，不改变坐标或 XML 内图片路径。`AllowClip` 对应原界面“允许裁切触及标注区域”，默认关闭；具体 XML 标注识别与保护逻辑保留在原核心中。本轮不扩展其识别格式，也不把其他点集文件转换为新格式。

每批创建 `convert_本地时间_唯一后缀/`，包含 images、summary.json、events.jsonl。summary schema 为 `vt-toolbox-conversion/1`，记录参数、核心哈希、固定原点、成功数量、原报告、输出图像路径与状态。complete 表示全部成功；partial 表示有跳过/失败；cancelled 表示取消；failed 表示协议或执行异常。异常、取消均保留已完成输出。

## 与缺陷合成交接

只有操作者点击“作为 OK 底图送往缺陷合成”才交接，不自动推断转换图是否正常。已输出图片通过缺陷模块 add_ok 逐一验证，支持 L 灰度及 RGB；保留颜色模式，NG 素材须同模式，灰度与 RGB 分批合成。若缺陷模块忙碌则拒绝当前交接，避免改动运行中的底图列表。

原缺陷 schema `vt-defect-lab/1` 不变；旧灰度配方仍可加载。工具6.1.0新增RGB支持和可选通道背景字段，原字段含义不变。命令行和GUI使用同一合成引擎，详见 [AI接口](04-AI命令行接口.md)。

6.2在NG画布增加独立生成范围模式；范围归一化后仍写入原有Settings.roi，在OK/预览画布显示范围和原NG位置参考，保存配方供GUI及CLI共同复用。坐标映射及缺失原图的处理见 [NG生成范围](05-NG生成范围.md)。

6.3由NGDocument保存每图状态，NG列表支持多文件/文件夹导入和多项移除；PoolEntry向无Qt的pool.py提供已圈选素材和各自roi。GUI及CLI共用固定种子匹配和池配方，旧单素材接口保留，详见 [多NG素材池](06-多NG素材池.md)。共用Canvas将平移改为右键拖动，右键单击仍可收尾多边形，转换页和缺陷页均生效。

6.4把数量控制放到右侧批量导出区，支持每张OK数量或本批精确总数，单素材/池批次共用generation_counts分配计划。新包独立输出到release/6.4.0/VTStudioToolbox，桌面入口更新到该版本，不强制关闭旧窗口。

## 打包与验收

6.5新增平铺ModeStrip工具及150ms选择动画，列表80～180逻辑像素自适应，手动/自动背景参考独立控件和小卡片空态；多框由Settings/PoolEntry.rois传到合成引擎。VT XML导出使用独立vt_xml.py，本机官方读取器验证位于verification/，官方程序集不会打入便携包。新包独立位于release/6.5.0/VTStudioToolbox，旧窗口不强制关闭。

便携目录是 release/VTStudioToolbox；核心位于 _internal/legacy/vt-engine.exe。构建自动启动新 EXE，检查两个模块、转换左上角像素、黑色补边、XML字节一致和底图交接，并验证灰度/RGB合成、24位BMP、NG范围映射及RGB配方/范围恢复。普通 GUI 启动另行检查窗口可见及响应。

测试覆盖原合成行为、原转换核心行为、同名 XML 点集保护以及同窗口整合工作流。测试截图使用明确标识的人工数据，不作为真实 AI 训练效果证明。其他电脑、实际标注数据边界与 VT 专用标注导入仍需项目实测。
