# 界面操作与多个生成范围

最后更新：2026-11-13

背景参考值一行分为等宽两半：左为手动1～255输入，右为自动勾选。自动时输入置灰、不可编辑，合成仍按NG周边估计，RGB分别估计通道背景；取消勾选恢复手动输入。同会话切换自动不会清空手动值，配方保存实际使用的自动/手动参数；旧reference_gray=0配方恢复为勾选自动。

OK和NG列表按行数调整高度，最小80、最大180逻辑像素（随系统DPI缩放）；超过最大高度滚动显示，删除后缩小。无需手动拖动列表高度。

三页画布均使用平铺工具。NG页有矩形素材、多边形素材、生成范围、浏览平移；OK页有生成范围与浏览平移；预览页可切换查看图像/改动区域。选中按钮有浅橙状态及150ms滑动标记，支持普通Qt键盘焦点操作。右键拖动平移、滚轮缩放，多边形以右键单击或Enter完成。

没有图像时显示居中的320×180小卡片，图像载入后恢复完整画布。标题和页脚不再显示离线/GPU说明。小窗口通过参数栏滚动保留画布空间。

## 多个范围

1. 提取素材后点击“生成范围”，连续拖动即可追加。NG上的框按比例映射到OK；也可在OK上追加，每份NG分别保存。
2. 侧栏列出编号和坐标，点击某项可查看；“删除选中范围”只删该框，“撤销上一框”删除最后一框，“恢复全图/清空范围”取消全部限制。删除范围不会删除素材。
3. 生成时从能放进完整缺陷的框中随机选用一个；框间空白不属于允许范围，多个框不合成一个大外接框。过小框跳过，全部放不下会报错，不裁断缺陷。
4. 预览实线框对应本次选用范围，其他框作为虚线参考。JSON记录所有框与实际选中索引；多个框和未完成NG的范围均可随素材池配方恢复。

每份NG最多64个矩形。老单框配方仍可读；包含rois的多框配方需6.5或以上版本。

## 7.2共享控件

四个工作区共用细箭头下拉框、白色选项面板、浅橙选中态及输入边框。主表单36px、表格/窄字段28px；数字输入保留原NoButtons设置，带按钮时为横向减/加。只替换Qt默认组合框列表，定制view/delegate保留；动态NG类型/独立信号下拉也初始化。内嵌编辑框没有双边框，焦点边框不跳动；自动背景参考仍灰置禁用。相机参数界面与配置见13。

7.5.1修复弹出列表行位置缓存：Show时立即及下一事件循环刷新布局，避免表格内紧凑组合框继承样式后，旧行位置与新绘制高度不一致而重叠。默认列表不另加QListView外部spacing；标准弹出框按实际行高补足可用高度，并约束在屏幕工作区内，空间不足或选项多时仍可滚动。定制view/delegate只刷新布局，不套用默认弹出框的尺寸调整；不修改model、itemData、当前值或业务信号。
