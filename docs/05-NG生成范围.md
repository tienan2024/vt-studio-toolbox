# 在 NG 上设置合理生成范围

最后更新：2026-10-27

## 两个框分别做什么

“取缺陷”决定迁移哪一小块素材；“框选生成范围”决定它可以出现在什么材料区域。两个框互相独立，可以先框范围，也可以先取素材。

6.5已支持多个允许框：点击平铺的“生成范围”后连续拖动追加，每份NG最多64个，侧栏可删除选中或撤销上一框。旧单框配方照常读取；详见[新版多范围操作](08-界面与多范围.md)。下文单矩形坐标规则对每个框分别成立。

## 操作步骤

1. 导入同款、位置对应的真实 OK 底图，打开完整 NG 图。
2. 用“矩形取缺陷”或“多边形取缺陷”提取实际缺陷素材。
3. 点击左侧“在 NG 上框生成范围”，或在 NG 页工具栏选择“框选生成范围”。在 NG 上另框允许出现此缺陷的材料区域，可比素材选区大。此操作不会重新裁取素材。
4. 切到“OK 底图 / 允许区域”查看映射。绿色实框是允许范围；蓝色虚框是原 NG 素材位置的比例参考。左侧显示当前底图的范围坐标。
5. 如需修正，点击“在 OK 上微调”重新拖框。点击“恢复全图”取消范围限制，保留素材。NG页清除选区根据当前选择用途清除素材或恢复范围；切到浏览模式后仍保留上一个用途。
6. 生成预览并检查，再批量导出。预览中绿色框对应该次结果的实际范围。保存配方会保存范围，CLI使用该配方也会沿用。

## 坐标与放置

例如NG为400×320，框选 `(100,80)→(300,240)`，保存的比例为 `[0.25,0.25,0.75,0.75]`。OK为800×640时对应 `(200,160)→(600,480)`。引擎按左/上向下取整、右/下向上取整得到像素范围。

每个缺陷的整个旋转后素材外接矩形都须落在该范围内，实际修改像素也不会出框。范围过小时明确报错，不自动扩大区域、挪到其他材料或裁掉缺陷；可扩大范围、降低尺寸倍率或减小旋转范围后重试。

范围按比例映射，缺陷素材大小仍由原有倍率决定。此功能不做产品配准、材料分类或相似性识别。OK/NG位置不对应、存在不同裁切时，应在OK上重新核对调整。

切换OK时保留当前NG范围；6.3切换NG会恢复该NG自己的素材与范围，新导入NG初始为全图。更换产品或材料布局后，应重新核对范围，或分素材池处理。

## 配方及缺失原图

旧单素材配方使用 `settings.roi`，仍可加载；6.3素材池配方使用每项 `entries[].roi` 保存各NG范围，恢复后标记为“配方范围”。原NG文件丢失时，内嵌素材和已保存范围仍可生成；不能在小素材裁图上重新提取缺陷或框完整NG范围。此时可重新导入完整NG，或在OK上微调该NG的生成范围。

JSON标注的 `allowed_roi_xyxy` 是每张结果的实际底图像素范围，`placement_xyxy` 是素材放置框，`bbox_xyxy` 是实际改动像素包围框；输出仍保留原底图尺寸和颜色模式。
