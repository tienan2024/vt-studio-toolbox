# 批量生成图片数量

最后更新：2026-10-27

右下角“批量导出”区直接设置数量，旁边显示预计合计和使用OK张数。数量修改不会重新计算单张预览；生成期间禁用数量控件。

| 方式 | 设置与结果 |
|---|---|
| 每张 OK 生成 | 每张1～1000张，保持原默认方式。3张OK×每张5张=15张。 |
| 本批生成总数 | 本批1～100000张，输入100即合计100张，不再乘OK数量。 |

总数方式按OK列表顺序尽量均匀分配。例如3张OK生成8张，分配为3、3、2；生成2张时为1、1、0，只使用前两张。零分配OK不读图、不参与匹配或预检；计划仍在summary中列出，配方保留完整底图列表。每张模式仍使用全部OK。

所有分配到数量的OK仍须有可用NG；总数方式不会放宽颜色模式、生成范围或尺寸条件。取消/失败时保留已完成数据，实际张数以completed和manifest为准；正常完成时严格等于计划总数。掩膜与JSON不计入图片数量。

保存配方会保留数量方式。旧配方未含total_samples时按每张数量；精确总数配方设置正整数total_samples，需6.4或更高版本读取。按每张方式保存时省略该字段。重新导入不同数量OK时，总数方式仍保持总量，每张方式会随OK数量改变总量。

CLI使用 `--total 100` 或 `--count 5`，不可同时指定；省略时沿用配方。--count显式关闭原配方的总数方式。summary.quantity_mode为total/per_ok，planned_ok_counts逐项记录source_ok与计划count，total为计划合计，completed为实际完成数量。
