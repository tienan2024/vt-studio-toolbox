## v1.0.1 便携版启动修复

旧包实际启动曾出现 `QtCore` DLL 导入错误，不能以源码测试通过替代便携版验收。

已查明误收集的 `icuuc.dll` 来源是 Codex 运行环境的 Poppler 目录，导出 ICU 78 带版本符号；Qt 的导入表要求 Windows 系统 ICU 的未版本化符号。排除此同名库后，运行中的 Qt6Core 来自便携目录，icuuc 来自 `C:/Windows/System32/icuuc.dll`。

直接启动修复后的便携 EXE，`verification/portable_smoke.json` 记录 `status=passed`、`frozen=true`、Qt 6.11.1，成功生成 400 × 320 测试预览、导出两张 8 位灰度 BMP，并验证掩膜与变化像素一致。此为便携进程的功能验证，使用临时人工数据，不证明真实检测效果。构建脚本已将该验证作为成功门槛。
